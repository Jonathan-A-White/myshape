# MySHAPE best-practices audit

Written for the factory's planners and Builders. It measures MySHAPE against the owner's PWA checklist (the vault's `seats/builder/pwa-best-practices/checklist.md`, 31 lines) and the rules added on 2026-10-09 (the vault's `changelog.md` of the same folder), and turns the failures into ranked stories.

Status: a description of the code at commit 08c30ab (v1.0.9), audited 2026-10-10. Nothing was changed except this file and its test. `docs/best-practices-audit.test.ts` runs in `npm test`: it checks the shape of this file and that every `file:line` cited below still lies inside a real file. It does not check that a cited line still says what the audit says; when a landing moves code, refresh the row.

## How to read it

- **Status** is `pass`, `fail` or `n/a`. A checklist line with several parts is `pass` only when every part passes or is not applicable; the evidence names the part that fails.
- **Evidence** is a `file:line` in this repo, a command with its result, or the reason a line is `n/a`. Commands were run on 2026-10-10 in a clean checkout.
- **Fix** is the smallest change that turns the row to `pass`; **Size** is S (a few lines to one hour), M (one story, one session) or L (does not fit one story; split it).
- MySHAPE is one PWA: a client-only React 19 / Vite app with Dexie, deployed to GitHub Pages at `/myshape/`. It has no Android app and no server, so there is no part of it that is not a PWA. The rows that are `n/a` are `n/a` because the app has no such feature (no speech, no photos, no server, no model), not because a part is exempt.

Totals: of the 31 checklist lines, 6 pass, 20 fail and 5 are n/a. Of the 6 rules added 2026-10-09, 1 passes, 2 fail and 3 are n/a.

## Ranked fix stories

Most value to the owner first. Each is one story for a Builder unless it says otherwise. "Rows" names the table rows it turns to pass. A story that edits `src/index.css`, `index.html` or `vite.config.ts` collides with the others that do; file them one after another.

1. **Draw real app icons** (rows C21, C3 in part; size M). A black square is what the owner sees on his home screen.
